# Stone Paper Scissors Game

## Project Overview

This project is a browser-based Stone Paper Scissors game developed using HTML, CSS, and JavaScript. It allows users to play the classic game against the computer through an interactive user interface.

The project focuses on front-end development, game logic, and user interaction.

## Objectives

- Build an interactive browser-based game.
- Implement the rules of Stone Paper Scissors using JavaScript.
- Practice DOM manipulation and event handling.
- Create a simple and user-friendly gaming interface.

## Technologies Used

- **HTML:** Used to structure the game interface.
- **CSS:** Used to style the game layout, buttons, and visual elements.
- **JavaScript:** Used to implement game logic, computer choices, and result calculation.

## Features

- Interactive buttons for choosing Stone, Paper, or Scissors.
- Computer-generated random choices.
- Automatic result calculation based on game rules.
- Display of the game result, such as win, lose, or draw.
- Simple and user-friendly interface.
- Score tracking, if implemented.

## Game Rules

- **Stone beats Scissors.**
- **Scissors beats Paper.**
- **Paper beats Stone.**
- If both the player and computer choose the same option, the result is a draw.

## How to Run the Project

1. Clone or download this repository.
2. Extract the project files if downloaded as a ZIP.
3. Open the project folder.
4. Open `index.html` in a web browser.
5. Choose Stone, Paper, or Scissors and play against the computer.

No backend or database is required.
